Kayato MobileConfig Studio

Create, sign and inspect iOS configuration profiles.

A local-first studio for .mobileconfig files. Generate common payloads, sign CMS/PKCS#7 profiles, extract signed content and prepare files for Safari installation.

Prepare an installable profile

Use a local file, a direct HTTPS URL or pasted XML/Plist content.

Generate a profile

Build common mobileconfig payloads without any external repository files.

Sign a .mobileconfig profile

Default mode only needs a profile file. The automatic signer appears as Kayato.

Kayato mode needs no extra key or certificate. iOS may show Not Verified because the certificate is self-signed.

Unsign a signed profile

Extract XML content from a CMS/PKCS#7 signed mobileconfig file so it can be inspected, edited or signed again.

Kayato MobileConfig Studio runs as a static local-first web app.

Safari recommended

iOS requires Safari to open the configuration profile installation screen. Open this page in Safari on iPhone or iPad.
